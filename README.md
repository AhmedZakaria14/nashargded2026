# Nashar Digital

موقع وكالة نمو رقمي متعدد الصفحات بهوية أصلية جديدة، مستوحى من عمق وتجربة الموقع المرجعي من حيث بنية الصفحات والتفاعل، مع محتوى وتصميم بصري خاص بـ Nashar Digital.

## المزايا

- واجهة RTL عربية متجاوبة بالكامل
- نسخة إنجليزية
- قائمة رئيسية وMega Menu وقائمة هاتف كاملة الشاشة
- Scroll reveal animations وprogress indicator وcustom cursor وmagnetic CTAs
- صفحات خدمات منفصلة
- Portfolio مع تصفية
- Blog ومقالات داخلية
- Contact / FAQ / Careers / Privacy
- تصميم Responsive للكمبيوتر والتابلت والهاتف
- إعداد Vercel للروابط النظيفة والصفحات الداخلية

## التشغيل

المشروع Static Vanilla HTML/CSS/JavaScript ولا يحتاج build step. يمكن نشره مباشرة على Vercel من فرع `main`.

## الملفات الرئيسية

- `index.html` — shell العام للموقع
- `styles.css` — الهوية البصرية والاستجابة والحركات
- `app.js` — المحتوى، routing، التفاعلات والصفحات
- `vercel.json` — rewrites للروابط الداخلية
